info 1. 總則

歡迎使用由 Mikan Network（以下簡稱「我們」）開發的 Tsumiru UWP（包識別碼：MikanNetwork.TsumiruUWP，以下簡稱「本應用程式」）。本應用程式是一款面向 Suwayomi Server 的自由開源 Windows 客戶端。

我們極度重視您的隱私權。本政策完全依循微軟應用程式商店認證規範（Microsoft Store Policy 10.5.1 個人資訊與隱私權政策）撰寫，公開且透明地說明本應用程式存取、處理及保護您的個人資訊之方式。

security 2. 我們存取與處理的資訊（微軟審查重點項目說明）

為了實現漫畫離線瀏覽與自建伺服器連線功能，本應用程式在 Windows 10 / 11 系統上需要使用以下權限與資訊：

folder 裝置上的文件、資料夾與檔案 (Documents / Device Folders and Files)

  • 離線漫畫快取與下載： 當您主動下載或線上閱讀漫畫時，章節圖片與封面快取僅儲存於本應用程式私有的 UWP 隔離沙盒目錄（ApplicationData.Current.LocalFolder 與 LocalCacheFolder），讓您可在無網路時順暢閱讀。
  • 閱讀進度與書籤： 您的漫畫歷史閱讀進度、書籤與自訂偏好以本機輕量設定（JSON）儲存於設備端。
  • 備份與還原檔案（FilePicker）： 僅當您主動觸發「匯出備份」或「還原備份」時，本應用程式才會呼叫系統原生檔案選取器（FilePicker）讀取或寫入您指定之單一備份檔案。
零越界保證： 本應用程式絕不掃描、讀取或收集您裝置中的「我的文件」、「圖片」、「下載」等公共非關聯目錄，所有檔案絕不上傳至開發者伺服器或任何第三方。

language 網路連線與 IP 位址 (IP Address & Network Access)

  • 直連您的 Suwayomi 伺服器： 當本應用程式發起網路連線時，僅向您親自配置的 Suwayomi 伺服器網址（例如家庭區域網路 IP http://192.168.x.x:4567 或您的私有網域）直接發送標準 HTTP/WebSocket 請求。傳輸過程中底層 TCP/IP 協定會自然傳送您的設備 IP 位址。
  • 區域網路權限 (Private Network)： 清單宣告之 privateNetworkClientServer 專為允許 Windows 10 Mobile 裝置與桌面 PC 連線至家庭 Wi-Fi 內的自建伺服器。
  • 圖源圖片直連： 漫畫章節圖片與擴充套件僅在您的設備與目標圖源伺服器之間進行標準資料傳輸。
零中繼伺服器宣告： 開發者（Mikan Network）沒有建立任何代理、中繼或流量記錄伺服器。您的網路流量從不經過開發者端，我們不記錄、不收集、不分析您的 IP 位址或閱讀瀏覽行為。

vpn_key 伺服器登入憑證 (Credentials)

  • 若您的 Suwayomi 伺服器啟用了帳號密碼或 JWT 權杖，該憑證僅保存在您本機的受保護密碼庫中，僅在與您自己的伺服器通訊時隨標頭發出，絕不外流。

block 3. 零廣告與零第三方追蹤披露

本應用程式堅守開源純淨原則：

  • 無商業廣告： 不包含任何橫幅廣告、開屏廣告或廣告聯盟 SDK。
  • 無第三方統計 SDK： 不包含 Google Analytics、Firebase、友盟等任何使用者行為追蹤代碼。
  • 本機偵錯記錄： 應用程式錯誤記錄僅存放於本機快取供使用者自我排錯，絕不自動回傳。

manage_accounts 4. 使用者控制權與資料抹除

您對儲存在本機的資料擁有完全支配權：

  • 清除快取： 隨時可在應用程式設定中一鍵清空漫畫離線快取與暫存圖檔。
  • 登出伺服器： 於連線頁面點擊登出即可徹底抹除本機儲存的伺服器金鑰與連線記錄。
  • 徹底移除： 於 Windows「設定 → 應用程式」中解除安裝本應用程式，系統將自動物理抹除本應用程式沙盒中的全部資料。

info 1. Introduction

Welcome to Tsumiru UWP (Package Identity: MikanNetwork.TsumiruUWP, "the Application"), developed by Mikan Network ("we," "our," or "us"). Tsumiru is a free, open-source third-party Windows client designed for Suwayomi Server.

We respect your privacy and are committed to protecting your personal information. This Privacy Policy strictly complies with Microsoft Store Policy 10.5.1 (Personal Information - Privacy Policy) and transparently details how the Application accesses, uses, and safeguards device permissions and data.

security 2. Information We Access and Process (Audit Items Disclosure)

To deliver core reading features and self-hosted server connectivity, the Application requests and utilizes the following permissions under Windows 10 / 11:

folder Documents (Device Folders and Files)

  • Offline Manga Cache & Chapter Downloads: When you read online or download manga for offline access, image files and cover thumbnails are stored strictly inside the Application's private, sandboxed app data directories (ApplicationData.Current.LocalFolder and LocalCacheFolder).
  • Reading History & Bookmarks: Your reading progress, local library states, and display preferences are stored locally as structured JSON data within the sandboxed storage.
  • Backup Export and Restore (FilePicker): Only when you explicitly initiate "Export Backup" or "Restore Backup", the Application invokes the Windows native FilePicker dialog to access the specific single backup file you choose.
Zero Invasion Guarantee: Tsumiru does NOT scan, read, index, or harvest files from your personal Documents, Photos, Downloads, or system directories. No stored files are ever transmitted to the developer or any third-party servers.

language IP Address and Network Access

  • Direct Connection to Your Suwayomi Server: Network communications occur exclusively between your device and the server endpoint explicitly configured by you (such as your home local network IP http://192.168.x.x:4567 or your personal private domain). During standard TCP/IP handshakes, your device IP address is naturally transmitted as part of Internet networking protocols.
  • Private Network Capability: The declared privateNetworkClientServer capability exists solely to allow Windows 10 Mobile and Desktop devices to connect to self-hosted Suwayomi instances across your home Wi-Fi local network.
  • Direct Manga Source Fetching: Manga chapters and image assets stream directly between your device and the target manga source servers.
Zero Intermediary Relay: The publisher (Mikan Network) operates no proxy, relay, or traffic collection servers. Your network traffic never passes through us. We do NOT collect, log, track, or monitor your IP address or reading activity.

vpn_key Server Authentication Credentials

  • If your Suwayomi Server requires authentication (HTTP Basic Auth or session tokens), credentials are encrypted and stored in your device's local secure storage (PasswordVault) and sent only in headers directly to your configured server.

block 3. Zero Advertisements & Zero Third-Party Trackers

Tsumiru is built with strict privacy and open-source principles:

  • No Advertisements: Contains no banner ads, interstitial promotions, or commercial advertising SDKs.
  • No Analytics or Trackers: Does not integrate Google Analytics, Firebase, or any behavioral telemetry libraries.
  • Local Diagnostic Logs: Crash logs are recorded strictly in local temporary storage for user troubleshooting and are never uploaded automatically.

manage_accounts 4. User Controls and Data Erasure

You retain full authority and ownership over all stored data:

  • Clear Cache: You can purge cached manga pages and temporary images at any time via App Settings.
  • Disconnect Server: Logging out from the Connection page immediately wipes saved authentication tokens from local storage.
  • Complete Uninstallation: Uninstalling the Application via Windows Settings automatically and permanently removes all sandboxed files, downloads, and preferences from your system.

verified 5. Microsoft Store Policy Compliance

This Privacy Policy serves as the official, binding disclosure satisfying Microsoft Store Policy 10.5.1. We do not sell, rent, trade, or transfer personal data to any external parties.
